# 海淀学校田径操场 PU + Query 误检诊断实验设计

## 目标

使用海淀区 OSM 学校田径操场面标注，模拟真实用户仅提交少量 Polygon 的情况，
完整运行当前 PU + Query 训练与跨 Patch 推理。确认操场误检是否存在，量化真实
操场、困难背景和普通背景的得分差异，并比较阈值及空间约束方法。

本阶段只做离线实验，不修改线上 API 行为。实验结论通过后再单独设计生产修复。

## 操场定义

仅纳入典型学校田径操场：

- `leisure=track` 且 `sport=athletics`
- `leisure=pitch` 且 `sport=athletics`
- 名称或周边学校语义能确认是田径场的完整面

排除普通篮球场、网球场、单独足球场、体育馆和无法形成可靠面积的线要素。
对跑道与内场分别绘制的对象，允许在证据充分时合并为完整操场 Polygon。

OSM 标签只作为不完整参考真值。未被 OSM 标注的真实操场不能直接计为误检，
需要结合高分辨率光学影像人工复核。

## 数据与隔离

- 区域：海淀区
- 时间：优先使用 2026 年 4 月 P10C 64 维 embedding 与同期高分辨率光学影像
- 支持集：从若干 OSM 操场中选取少量 Polygon，模拟真实用户标注
- 校准集：与支持集不同的 Patch，用于选择阈值
- 测试集：其余含操场 Patch 加随机背景 Patch

支持、校准和测试 Patch 不重叠。所有样本选择规则和 OSM 元素 ID 写入清单。

## 对照方法

### A. 当前 PU + Query

直接调用 `train_pu_query` 和 `score_pu_query`，使用模型自动学习的阈值，
作为线上逻辑基线。

### B. 更严格的固定阈值

在校准集上扫描阈值，重点比较 Precision、Recall、F1、IoU、预测面积率和每
Patch 误检连通区域数量。阈值只在校准集选择，测试集不参与调参。

### C. 双阈值与连通区域约束

使用高阈值产生可靠种子，低阈值产生候选范围，只保留与高置信种子连通的候选
区域。再过滤面积过小的碎片。形状指标仅用于诊断，不先验硬编码“跑道必须是
椭圆”，避免将不规则学校操场直接排除。

## 得分诊断

分别统计：

- OSM 操场内部像素
- 操场边界邻域
- 高分误检连通区域
- 随机未标注背景

展示各组的均值、中位数、分位数、直方图和箱线图。对高分误检区域计算其与
前景原型、背景原型的余弦相似度，判断误检来自前景相似、背景模型不足，还是
Query adaptation 扩张。

## 可视化

每个案例横向展示：

1. 高分辨率光学影像
2. OSM 参考标签
3. 模型可见的少量训练标签
4. PU + Query 连续得分热图
5. 当前阈值预测
6. 严格阈值预测
7. 双阈值连通约束预测
8. 最终结果叠加

页面支持点击放大，并清楚标注训练 Patch、校准 Patch和独立测试 Patch。

## 验收标准

- 至少取得 3 个可信学校田径操场 Polygon；不足时明确报告 OSM 覆盖限制。
- 支持、校准、测试 Patch 无交叉。
- 输出原始基线与至少两种改进对照，不只展示改进后的结果。
- 报告操场和误检区域得分分布，以及每种方法的 Precision/Recall/F1/IoU。
- 不用测试标签直接选择阈值，不把 OSM 未覆盖区域自动当作负样本。
- 形成可复现实验清单、JSON 指标和可放大 HTML 页面。

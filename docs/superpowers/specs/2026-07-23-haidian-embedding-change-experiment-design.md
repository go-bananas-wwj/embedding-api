# 海淀 Embedding 变化检测对照实验设计

## 目标

使用海淀区 P10C 64 维 embedding，对比 2025 年 12 月（`202512`）与
2026 年 4 月（`202604`）的逐像素语义变化。实验只生成可视化和统计结果，
不修改正式 API。

## 对照方法

### 方案一：余弦变化距离

先对每个像素的 64 维向量做 L2 归一化，再计算：

`cosine_change = 1 - cosine(embedding_202512, embedding_202604)`

该指标主要反映语义方向变化，对向量整体模长不敏感。

### 方案二：归一化欧氏距离

对两期向量分别做 L2 归一化，再计算：

`euclidean_change = ||normalized_202512 - normalized_202604||`

该指标保留归一化后向量间的几何距离，用作余弦变化距离的对照。

## 数据与抽样

- 区域：海淀区。
- Embedding 版本：`v1`，即 P10C 64D embedding。
- 对比月份：`202512` 与 `202604`。
- 从两个月份均具有 embedding 和 Sentinel-2 光学影像的 Patch 中抽样。
- 优先选择变化分数分布覆盖低、中、高三个区间的约 12 个代表性 Patch，
  同时保留抽样和排序依据，避免只展示最好看的结果。

## 可视化

每个 Patch 横向展示：

1. `202512` Sentinel-2 光学影像。
2. `202604` Sentinel-2 光学影像。
3. 余弦变化距离热力图。
4. 余弦变化距离叠加图。
5. 归一化欧氏距离热力图。
6. 归一化欧氏距离叠加图。

颜色使用统一的蓝到红连续色标：蓝色表示变化小，红色表示变化大。所有 Patch
共用基于全体有效像素分位数确定的色标范围，避免每张图单独拉伸造成错误比较。
网页支持点击图片放大，并明确标注月份、算法、色标范围和 Patch ID。

## 统计

每个 Patch 展示两种指标的均值、P90、P95，以及超过全局高变化阈值的像素占比。
页面顶部给出两种指标的整体分布和相关性，帮助判断两种算法是否产生一致排序。

## 数据质量处理

- 对非有限值、零向量和无效影像像素建立统一有效掩膜。
- 光学影像使用稳健分位数拉伸，避免黑块由显示范围错误造成。
- 两期数组空间尺寸必须一致；不一致的 Patch 记录为失败项，不做隐式错位缩放。
- 热力图只表达 embedding 变化强弱，不直接宣称地物真实发生变化。

## 验收标准

- 两种算法使用同一批 Patch 和同一有效像素掩膜。
- 所有热力图使用跨 Patch 的统一色标。
- 页面可访问、图片可放大、标题为中文。
- 页面列出失败或缺失数据，不静默跳过。
- 输出保存在 `Tmp` 下，并通过当前静态服务提供浏览地址。
